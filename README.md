2. 패치 적용 방법 — xdelta UI 1.1 (Windows)

xdelta UI는 별도로 준비해 압축을 풉니다.
배포 페이지(보관본): https://www.factionfiles.com/ff.php?action=file&id=5686
xdeltaUI.exe와 함께 들어 있는 xdelta.exe는 같은 폴더에 두세요.

1) 한글패치 ZIP을 압축 해제합니다.
2) xdeltaUI.exe를 실행하고 “Apply Patch” 탭을 선택합니다.
3) “Patch” 오른쪽 “Open...”을 눌러 아래 패치를 선택합니다.
   TokyoMajinGakuen_Korean_20261004_r5.xdelta
4) “Source File” 오른쪽 “Open...”을 눌러 수정되지 않은 일본판 원본
   .nds 파일을 선택합니다. 기존 한글판이나 트리밍 ROM은 사용하지 마세요.
5) “Output File” 오른쪽 “...”을 눌러 저장 위치와 새 파일명을 지정합니다.
   예: TokyoMajinGakuen_Korean.nds
   파일명 끝에 .nds를 직접 붙이고 원본과 다른 파일명을 사용하세요.
6) 아래쪽 “Patch” 버튼을 누르고 완료 안내가 나올 때까지 기다립니다.
7) 만들어진 .nds 파일의 크기와 체크섬을 아래 항목과 비교한 뒤 실행합니다.

오류가 나면 Patch와 Source File을 바꾸어 선택하지 않았는지, 원본의 크기와
체크섬이 1번 항목과 같은지 확인하세요. Output File에는 새로 생성할 파일명을
지정해야 합니다. 체크섬 검사를 끄지 말고 원본 파일을 다시 확인하세요.

배포 패치를 원본에 적용하면 검증된 한글 ROM과 내용이 일치하는 것을
xdelta3 3.1.0와 Rom Patcher JS 엔진에서 각각 확인했습니다.

Windows PowerShell에서 확인하는 예:
Get-FileHash -Algorithm SHA256 -LiteralPath ".\TokyoMajinGakuen_Korean.nds"

함께 제공되는 SHA256SUMS.txt는 배포 파일의 손상 여부를 확인할 때 사용합니다.
게임 ROM의 해시는 위 값을 기준으로 확인하세요.

4. 저장 파일과 실행

- 기존 저장 파일(.sav)을 먼저 별도 폴더에 백업하세요.
- 이어서 플레이할 때는 사용하는 에뮬레이터의 저장 폴더에서 ROM과 저장
  파일의 기본 이름을 맞추세요. 예: TokyoMajinGakuen_Korean.nds와
  TokyoMajinGakuen_Korean.sav. 저장 경로는 에뮬레이터 설정에 따릅니다.
- 패치 교체 후에는 에뮬레이터를 완전히 종료하고 새 ROM으로 다시 실행하세요.
- 이전 ROM에서 만든 강제 저장(세이브스테이트)은 옛 글자·화면 데이터를
  복원할 수 있습니다. 새 ROM을 부팅한 뒤 게임 내 일반 저장을 불러오세요.
- 이번 패치로 이전 저장 데이터의 기록이 소급 수정된다고 보장하지 않습니다.
